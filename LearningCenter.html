HTML

Build the structure of a web page

1. Document structure

HTML describes the structure and meaning of page content. A normal document has a doctype, html, head, and body.

Example 
<!doctype html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    Hello
  </body>
</html>
What this shows: The title shows on the browser tab. Everything inside body is what visitors see on the page.
2. Headings and paragraphs

Use headings to organize content and paragraphs for normal text. Keep the heading order meaningful.

Example 
<h1>Cyber Nexus Academy</h1>
<h2>My Subjects</h2>
<p>Welcome to the learning center.</p>
What this shows: Use one h1 for the page title, then h2 for sections and h3 for sub-sections. Don't skip levels just to make text bigger.
3. Links and images

Links move users to another page or section. Images add visual content and should have useful alt text.

Example 
<a href="Dashboard.html">Dashboard</a>
<img src="Vid,Aud,Pic/LOGOACADEMY.png"
     alt="Cyber Nexus Academy Logo">
What this shows: href is where the link goes. alt is the text read aloud by screen readers and shown if the image fails to load.
4. Lists

Use unordered lists for grouped items and ordered lists when sequence matters.

Example 
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Plan</li>
  <li>Build</li>
  <li>Test</li>
</ol>
What this shows: ul shows bullet points. ol shows numbers 1, 2, 3 automatically.
5. Forms

Forms collect information. Labels, inputs, selects, textareas, and required validation make forms easier to use.

Example 
<form>
  <label for="email">Email</label>
  <input id="email" type="email" required>

  <label for="year">Year Level</label>
  <select id="year">
    <option>1st Year</option>
    <option>2nd Year</option>
  </select>

  <button type="submit">Send</button>
</form>
What this shows: The label's for must match the input's id. required stops the form from being sent while the field is empty.
6. Tables

Tables are useful for structured data such as gradebooks. Use table headers for column labels.

Example 
<table>
  <tr>
    <th>Subject</th>
    <th>Grade</th>
  </tr>
  <tr>
    <td>Web Technology</td>
    <td>95</td>
  </tr>
</table>
What this shows: th is a column heading, td is a normal cell, and each tr is one row.
7. Semantic HTML

Semantic elements communicate purpose. Common examples include header, nav, main, section, article, and footer.

Example 
<header>Cyber Nexus Academy</header>

<nav>
  <a href="Dashboard.html">Dashboard</a>
</nav>

<main>
  <section>
    <h2>My Subjects</h2>
    <article>Web Technology</article>
  </section>
</main>

<footer>2026 Cyber Nexus Academy</footer>
What this shows: Compare with <div><div><div>: the semantic tags tell browsers and screen readers what each part is for.
8. Attributes

Attributes provide extra information to an element. Examples include id, class, href, src, alt, and type.

Example 
<button class="primary" type="button">Save</button>

<a href="Dashboard.html" target="_blank">Open in a new tab</a>

<input id="studentName" type="text" placeholder="Full name">
What this shows: Attributes always go inside the opening tag, written as name="value".
9. Accessibility basics

Use labels for form fields, meaningful link text, alt text for informative images, and a logical heading structure.

Example 
<!-- Better -->
<label for="name">Full name</label>
<input id="name" type="text">
<img src="logo.png" alt="Cyber Nexus Academy logo">
<a href="grades.html">View my grades</a>

<!-- Avoid -->
<input type="text">
<img src="logo.png">
<a href="grades.html">Click here</a>
What this shows: A screen reader user hears "Click here" with no clue where it goes, but "View my grades" makes sense on its own.
10. HTML debugging

When a page looks wrong, inspect the element in the browser and check whether tags are closed and attributes are spelled correctly.

Example 
<!-- Broken: the quote after "card is missing
     and the p tag is never closed -->
<div class="card>
  <p>Hello
</div>

<!-- Fixed -->
<div class="card">
  <p>Hello</p>
</div>
What this shows: Right-click the page and choose Inspect. If an element looks wrong in the Elements panel, the problem is usually just above it.
11. Page sections

Use sections to group related content such as announcements, subjects, grades, and activities.

Example 
<a href="#subjects">Jump to subjects</a>

<section id="announcements">
  <h2>Announcements</h2>
</section>

<section id="subjects">
  <h2>My Subjects</h2>
</section>
What this shows: Giving a section an id lets a link such as href="#subjects" scroll straight to it.
12. Student challenge

Create a small student profile page with a heading, photo, list of subjects, and a contact form.

Example 
<h1>Andrew Zamora</h1>
<img src="photo.jpg" alt="Photo of Andrew">

<h2>My Subjects</h2>
<ul>
  <li>Web Technology</li>
  <li>Programming</li>
</ul>

<h2>Contact Me</h2>
<form>
  <label for="msg">Message</label>
  <textarea id="msg"></textarea>
  <button type="submit">Send</button>
</form>
What this shows: This is one possible answer. Try it first, then compare, and change the content so it describes you.

CSS

Style and arrange your interface

1. Selectors

Selectors choose which HTML elements receive styles.

Example 
body        { font-family: Arial; }   /* every body element */
#mainTitle  { font-size: 32px; }      /* the element with id="mainTitle" */
.card       { border-radius: 12px; }  /* every element with class="card" */
What this shows: Use element names for broad rules, classes for repeated styles, and ids for one unique element.
2. Colors and typography

Set readable text, spacing, and contrast. Use a small consistent type scale across a school dashboard.

Example 
body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
  color: #1d2433;
  background: #f4f7fa;
}

h1 { font-size: 32px; color: #080670; }
h2 { font-size: 24px; }
What this shows: Dark text on a light background (or the reverse) keeps the page easy to read. A line-height around 1.5 makes paragraphs comfortable.
3. Box model

Every element has content, padding, border, and margin. Understanding these makes spacing easier to control.

Example 
.card {
  padding: 20px;              /* space INSIDE the border */
  border: 1px solid #ddd;     /* the edge */
  margin: 12px;               /* space OUTSIDE the border */
}
What this shows: Think of a framed photo: the photo is the content, the matting is the padding, the frame is the border, and the gap to the next frame is the margin.
4. Flexbox

Flexbox is useful for navigation bars, rows, columns, and aligning dashboard cards.

Example 
<div class="row">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</div>

.row {
  display: flex;
  gap: 16px;
  align-items: center;
}
What this shows: The three boxes now sit side by side with 16px between them, centered vertically.
5. Grid

CSS Grid is useful when you need rows and columns for dashboards and learning cards.

Example 
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
What this shows: repeat(3, 1fr) means three equal columns. Six cards would fill two rows of three.
6. Responsive design

Use flexible widths and media queries so pages work on phones, tablets, and desktops.

Example 
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 700px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
What this shows: On screens 700px wide or smaller, the three columns become a single column.
7. Buttons and states

Style buttons for clear actions and provide hover or focus states so users know what is interactive.

Example 
button {
  background: #080670;
  color: #fff;
  padding: 10px 16px;
  border: 0;
  border-radius: 8px;
  cursor: pointer;
}

button:hover          { background: #1261a0; }
button:focus-visible  { outline: 3px solid #f5b301; }
button:disabled       { opacity: 0.5; cursor: not-allowed; }
What this shows: hover is when the mouse is over it, focus-visible is when it is reached with the keyboard, and disabled is when it can't be used.
8. Positioning

Normal flow, relative, absolute, fixed, and sticky positioning solve different layout problems. Start with normal flow when possible.

Example 
.topbar { position: sticky; top: 0; }        /* stays at the top while scrolling */

.card { position: relative; }                 /* anchor for the badge */
.card .badge {
  position: absolute;                         /* placed inside the card */
  top: 8px;
  right: 8px;
}
What this shows: An absolute element is positioned against the nearest ancestor that has position set, which is why the card needs position: relative.
9. Reusable classes

Keep repeated styles in classes instead of adding the same inline style to many elements.

Example 
<!-- Avoid: the same style repeated -->
<p style="color: red; font-weight: bold;">Late</p>
<p style="color: red; font-weight: bold;">Missing</p>

<!-- Better: one class, reused -->
<p class="warning">Late</p>
<p class="warning">Missing</p>

.warning { color: red; font-weight: bold; }
What this shows: To change the warning color later you edit one rule instead of every paragraph.
10. CSS variables

Variables can store repeated values such as a brand color, radius, or spacing unit.

Example 
:root {
  --brand: #1261a0;
  --radius: 12px;
}

.card   { border-radius: var(--radius); }
button  { background: var(--brand); }
What this shows: Change --brand once in :root and every rule that uses var(--brand) updates.
11. Forms and focus

Inputs should have enough padding and a visible focus state so students can tell where they are typing.

Example 
input {
  padding: 12px;
  border: 1px solid #cbd5e1;
  border-radius: 8px;
}

input:focus {
  outline: 3px solid #1261a0;
  border-color: #1261a0;
}
What this shows: Never remove the focus outline without giving a clear replacement, because keyboard users rely on it.
12. CSS challenge

Build a three-card subject layout and make it change to one column on a small screen.

Example 
<div class="subjects">
  <div class="subject">Web Technology</div>
  <div class="subject">Programming</div>
  <div class="subject">Databases</div>
</div>

.subjects {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.subject { padding: 20px; border: 1px solid #ddd; border-radius: 12px; }

@media (max-width: 600px) {
  .subjects { grid-template-columns: 1fr; }
}
What this shows: This is one possible answer. Resize your browser window to see the cards stack.

JAVASCRIPT

Make the page interactive

1. Variables

Use let for values that change and const for values that should not be reassigned.

Example 
const school = "Cyber Nexus";
let score = 0;

score = score + 10;
console.log(score);   // 10

// school = "Other";  // Error: const cannot be reassigned
What this shows: Default to const, and switch to let only when the value really has to change.
2. Data types

Common values include strings, numbers, booleans, arrays, objects, and null.

Example 
const name = "Andrew";                // string
const age = 19;                       // number
const isEnrolled = true;              // boolean
const subjects = ["HTML", "CSS"];     // array
const student = { name: "Andrew" };   // object
const middleName = null;              // null (intentionally empty)

console.log(typeof age);              // "number"
What this shows: typeof tells you what kind of value a variable holds.
3. Conditions

Use if, else if, and else when different actions are needed for different conditions.

Example 
let score = 82;
let message;

if (score >= 90) {
  message = "Excellent";
} else if (score >= 75) {
  message = "Passed";
} else {
  message = "Keep practicing";
}

console.log(message);   // "Passed"
What this shows: JavaScript checks each condition from the top and runs only the first block that is true.
4. Loops

Loops repeat work. for loops and array methods are common tools for rendering lists of students or subjects.

Example 
const subjects = ["HTML", "CSS", "JavaScript"];

for (let i = 0; i < subjects.length; i++) {
  console.log(subjects[i]);
}

subjects.forEach(function (subject) {
  console.log(subject);
});
// Both print: HTML, CSS, JavaScript
What this shows: forEach is shorter and avoids counter mistakes, while a for loop gives you more control.
5. Functions

Functions package reusable behavior and can receive values through parameters.

Example 
function greet(name) {
  return "Hello " + name;
}

console.log(greet("Andrew"));   // "Hello Andrew"
console.log(greet("Louis"));    // "Hello Louis"
What this shows: Write the function once, then call it with different values as often as you need.
6. DOM

JavaScript can find HTML elements, change their text, respond to clicks, and build interactive forms.

Example 
<h1 id="title">Welcome</h1>

<script>
  document.getElementById("title").textContent = "Updated";
</script>
What this shows: After the script runs, the heading on the page reads Updated instead of Welcome.
7. Events

Events let your code react to user actions such as clicks, typing, submitting forms, and changing a select box.

Example 
<button id="saveBtn">Save</button>

<script>
  const button = document.getElementById("saveBtn");

  button.addEventListener("click", function () {
    alert("Saved");
  });
</script>
What this shows: Clicking the button shows the Saved message. The first value is the event name and the second is the function to run.
8. Arrays

Arrays store lists such as subjects or students. map, filter, find, and reduce are useful for dashboard data.

Example 
const grades = [85, 92, 74, 98];

const passed = grades.filter(g => g >= 75);              // [85, 92, 98]
const curved = grades.map(g => g + 2);                   // [87, 94, 76, 100]
const first  = grades.find(g => g > 90);                 // 92
const total  = grades.reduce((sum, g) => sum + g, 0);    // 349
What this shows: filter keeps matching items, map changes every item, find returns the first match, and reduce combines everything into one value.
9. Objects

Objects group related values. A student object can contain a name, email, section, and program.

Example 
const student = {
  name: "Andrew",
  section: "A"
};

console.log(student.name);       // "Andrew"
student.section = "B";           // change a value
console.log(student.section);    // "B"
What this shows: Use a dot and the property name to read or change a value inside an object.
10. Local storage

Browser localStorage can keep prototype data between page loads. Real school systems should use a secure backend database.

Example 
localStorage.setItem("lastSubject", "Web Technology");

const last = localStorage.getItem("lastSubject");
console.log(last);   // "Web Technology"

// Objects must be saved as text
localStorage.setItem("student", JSON.stringify({ name: "Andrew" }));
const saved = JSON.parse(localStorage.getItem("student"));
What this shows: The value is still there after you refresh the page. localStorage only stores text, so use JSON.stringify and JSON.parse for objects.
11. Debugging

Use the browser console to inspect errors and test small pieces of JavaScript before connecting them to a larger project.

Example 
let score = 10;
console.log("score is", score);      // check a value
console.error("Something went wrong");

// Typical error message:
// ReferenceError: scroe is not defined
// Fix: the variable is spelled "score", not "scroe"
What this shows: Press F12 and open the Console tab. The error message names the file and line number where the problem happened.
12. JavaScript challenge

Create a button that increases a displayed score by one every time it is clicked.

Example 
<p>Score: <span id="score">0</span></p>
<button id="plus">+1</button>

<script>
  let score = 0;

  document.getElementById("plus").addEventListener("click", function () {
    score = score + 1;
    document.getElementById("score").textContent = score;
  });
</script>
What this shows: This is one possible answer. Try adding a reset button as an extra challenge.
